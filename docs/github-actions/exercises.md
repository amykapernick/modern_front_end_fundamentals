*Note:* you will need to create your own fork of the repo to be able to complete these exercises, as you need to have control over the repo.

## 6.1 Creating a GitHub Action

Create a workflow file for `.github/workflows/test.yml` and push to GitHub to check that the workflow appears in the Actions tab.

## 6.2 Triggering the Action

Create a new branch and submit a small change of code in a pull request to the `prod` branch. Check that the action is triggered and runs successfully.

*Note:* You don't need to merge the pull request, you can keep pushing the rest of the changes to your new branch and it will update the pull request as you go.

## 6.3 Actions Steps

Add steps to the workflow to setup the repo and install the dependencies. Check that it runs successfully.
